# HiLook Camera Recorder

Simple .NET Worker Service for recording video streams from HiLook/Hikvision IP cameras.

## Features

- Record RTSP streams from IP cameras
- Save recordings as MP4 files
- Automatic file rotation
- Automatic cleanup of old recordings
- Run as a Windows Service
- Configuration via appsettings.json

## Technologies

- .NET 9
- Worker Service
- FFmpeg
- RTSP

## Future Plans

- Motion detection recording
- Multiple camera support
- Web management interface
- Recording history
- Email notifications
